### Pengantar penggunaan command list dengan option -D
---
Perintah ls di Linux digunakan untuk menampilkan isi direktori, dan opsi -D memungkinkan pengguna untuk menampilkan tanggal file atau direktori dalam format yang spesifik. Format tanggal ini mengikuti aturan yang sama seperti perintah date, sehingga pengguna bisa menyesuaikannya dengan kebutuhan, misalnya menampilkan hanya hari, bulan, tahun, atau jam dan menit. Dengan adanya opsi -D, informasi waktu file menjadi lebih mudah dibaca dan dipahami, terutama saat pengguna ingin membandingkan atau mengurutkan file berdasarkan tanggal tertentu.

Opsi -D biasanya digunakan bersamaan dengan opsi lain seperti -l agar informasi file ditampilkan lengkap dengan hak akses, pemilik, ukuran, dan tanggal modifikasi. Hal ini sangat berguna untuk manajemen file, pencatatan log, atau laporan yang memerlukan format tanggal tertentu. Dengan format tanggal yang dapat disesuaikan, pengguna memiliki fleksibilitas tinggi dalam menampilkan informasi file sehingga sesuai dengan standar atau kebutuhan dokumentasi tertentu.
---

### Cara penggunaan 

```
ls -D
```
